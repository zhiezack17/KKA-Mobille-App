LANGKAH 4 — PASTIKAN FOLDER UPLOAD WRITABLE (fix bug 500!)
  Ini penyebab HTTP 500 saat upload lampiran di server lama.

  Via aaPanel File Manager:
    1. Masuk ke folder public/uploads/
    2. Klik kanan → Permissions
    3. Set ke: 755  (Owner: Read+Write+Execute)
       atau 775 bila user web-server berbeda dgn owner
    4. Centang "Apply to sub-directories/files"

  Via SSH:
    chown -R www:www /www/wwwroot/kka/public/uploads
    chmod -R 775 /www/wwwroot/kka/public/uploads

  Pastikan juga folder master ada:
    mkdir -p /www/wwwroot/kka/public/uploads/master
    chmod 775 /www/wwwroot/kka/public/uploads/master

LANGKAH 5 — CEK PHP CONFIG (bila upload masih gagal)
  aaPanel → Software Store → PHP 8.1/8.2 → Setting → Config Modify
  Pastikan:
    upload_max_filesize = 20M
    post_max_size       = 25M
    memory_limit        = 256M
  Ekstensi wajib aktif:
    ✓ fileinfo   (deteksi MIME)
    ✓ pdo_mysql
    ✓ mbstring
    ✓ gd         (untuk foto)
  Setelah ubah config, restart PHP:
    aaPanel → Software Store → PHP → Restart

LANGKAH 6 — TEST DI BROWSER

  2. Sesi Audit → buka salah satu sesi → klik "Cetak / Preview"
     ✓ Pastikan kolom baru muncul (Pagu Anggaran, Realisasi,
       Dikwitansi, Selisih)

     ✓ Bila gagal → notif merah dengan pesan spesifik

  4. Menu Rekap per Desa → pilih filter Bidang

  5. Menu Master KKA (baru!) → klik "Buat Dokumen Baru"

LANGKAH 7 — BILA MASIH ADA MASALAH UPLOAD 500 SETELAH STEP 4-5
  Cek log error terbaru:
    aaPanel → Logs → pilih Website → "kka.arsipdigital..."
    → klik "View Error Log"

  ATAU via terminal:
    tail -50 /www/wwwroot/kka.arsipdigital-inspektorat.com/error_log
    tail -50 /www/server/php/82/var/log/php-fpm.log

  Sekarang log akan mengandung pesan detail dari [LampiranUpload],
  contoh:
    [LampiranUpload] sesi=14 file=foto.jpg size=6613436
      err=0 msg=Ukuran file (6.31 MB) melebihi batas 10 MB.

  Kirim ke saya baris [LampiranUpload] jika Anda temui, saya
  bantu diagnosa lebih lanjut.
